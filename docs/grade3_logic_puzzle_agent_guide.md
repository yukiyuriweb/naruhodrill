# 小学3年生向け・論理的思考力パズル作成 エージェント運用仕様書

本資料は、計算力や教科知識の暗記ではなく、**「条件を整理し、筋道を立てて答えを絞り込む力（純粋な論理的思考力）」**を養うパズル問題を生成するエージェントのための設計ガイドラインです。

---

## 1. 設計思想と「良い論理パズル」の4原則

エージェントが作成する問題は、すべて以下の4つの原則を満たさなければなりません。

1. **ルールが10秒で理解できる**: 小学3年生の日常知識だけでルールを把握でき、小4以降の算数公式・方程式・難解な専門用語（「対偶」「背理法」「グラフ」など）を一切使わずに解けること。
2. **「ひらめき一発」ではなく「論理の鎖」で解く**: 偶然思いつくクイズやなぞなぞではなく、「ここがこうだから、次はここが決まる」「もし〜だったら矛盾する」と順番に絞り込める構造にすること。
3. **大人が解いても「うっかりするとひっかかる」面白さがある**: 直感で飛びつくと間違えやすく、立ち止まって条件を確かめると「なるほど！」と納得できる仕掛け（落とし穴）を含めること。
4. **同型問題の量産を避ける**: 同じパズルの数字や登場人物（例：トランプ→動物カード、橋→駅）を変えただけの**同型コピーを作らず**、第2章に示す多様な思考メカニズムから毎回異なる切り口を選ぶこと。

---

## 2. 論理パズル「8つの思考メカニズム」カタログ

エージェントは、以下の8つのメカニズムを組み合わせて多様な問題を作成します。

| 型 | メカニズム名 | 使う思考法・コアの仕掛け | テーマ・題材例 |
| :--- | :--- | :--- | :--- |
| **型1** | **命題の確かめ（対偶・反例）** | 「AならB」を確かめるために「Bでないもの（反例になり得る場所）」だけを確認する | 裏返ったカード、封筒の中身、箱のシール |
| **型2** | **すべてウソのラベル（背理法）** | 「ラベルはすべてまちがい」などの強い否定条件から、1回の操作で全体を確定させる | 果物の箱、文房具の引き出し、お菓子の缶 |
| **型3** | **正直者とうそつき（矛盾のペア）** | 正反対の発言をする2人を見つけて「このどちらかがうそ」と絞り、残りの真偽を確定させる | 犯人探し、テストの順位、持ち物当て |
| **型4** | **天秤・測定の切り分け（3分割）** | 「はからない残りのグループ」も情報として使い、最小回数で1つを特定する | ニセモノのコイン、重いおもり、薬のびん |
| **型5** | **到達可能性（こわれた橋）** | 直接のつながりではなく「行ける／行けない」の矛盾から、通れる道・通れない道を確定する | 島の橋、迷路のドア、電車の路線 |
| **型6** | **局所制約の連鎖（線つなぎ）** | 角や最大本数など「1通りに決まる箇所」から始めて、ドミノ倒しで全体を埋める | 数字と線のパズル、マス目の塗り分け |
| **型7** | **順序・席順・対応表の推理** | 「AはBより前」「CとDは隣でない」などの断片条件を表や図で整理して1通りに絞る | 徒競走の順位、丸テーブルの席順、好きな食べ物 |
| **型8** | **状態遷移・手順の最適化** | 限られた条件（定員・容量など）の中で、矛盾なくゴールへ運ぶ最小手順を組む | 川渡りパズル、2つのコップでの水計量 |

## 3. 多様性を保つための作問ルール

### 3.1 「同じ仕掛け」の使い回し禁止
- 1つの問題セット（例：3〜5問）を作るときは、**必ず異なる型（第2章の型1〜型8）から選ぶ**こと。
- 同じ型をもう一度使う場合でも、単なる数値やキャラの置き換え（同型）にせず、条件の絡み方や制約の数を変えて別の推理手順が必要になるよう設計すること。

### 3.2 小学3年生向けの表現・表記ルール
- **漢字の配慮**: 小3までに習う漢字（440字）を中心に使い、小4以降の漢字を使う場合は必ず `確（たし）かめる` のようにふりがなを付ける。
- **専門用語の言い換え**:
  - 「対偶・反例」 → 「『〜でないもの』を調べる」「ルール違反になるか確かめる」
  - 「背理法・矛盾」 → 「もし〜だとしたら、ヒントと合わなくなる（おかしくなる）」
  - 「到達可能性」 → 「たどり着けるかどうか」
- **ビジュアルの活用**: 空間配置・ネットワーク・表を使う問題（型5・型6・型7など）は、文章だけで読ませず、必ずわかりやすい図（SVG等）や整理用の枠を添えること。

## 4. ベンチマーク問題集（目標水準の実例）

難易度の目線合わせとして、以下の3問（それぞれ異なるメカニズム）を基準にしてください。

### ベンチマークA：すべてまちがったラベルの箱（型2：背理法・情報の切り分け）
- **問題**: 3つの箱があり、それぞれ「りんごだけ」「みかんだけ」「りんごとみかんの両方」が入っています。ところが、3つの箱のラベルは**すべてまちがっています**。どれか1つの箱から中身を見ずに**1個だけ**取り出して見られるとき、すべての箱の中身を当てるには、どのラベルの箱から取り出せばよいでしょうか。
- **答え**: **「りんごとみかんの両方」のラベルの箱**
- **解説の核**: 「両方」のラベルはまちがいなので、中身は「りんごだけ」か「みかんだけ」のどちらかしかない。1個見ればその箱が確定し、残りの箱も「ラベルと一致しない」ことからすべて自動的に決まる（「りんご」や「みかん」の箱では「両方」の可能性が消せず1回で決まらない）。

### ベンチマークB：1人だけの「うそつき」を探せ（型3：矛盾のペア）
- **問題**: A、B、C、Dの4人のうち、**3人は本当のことを言い、1人だけうそをついています**。だれか1人がケーキを食べたことについて、4人は次のように言いました。食べたのはだれで、うそつきはだれですか。
  - A：「ぼくは食べていません。」
  - B：「ケーキを食べたのは、Cです。」
  - C：「ケーキを食べたのは、Dです。」
  - D：「Cの言っていることはうそです。」
- **答え**: **ケーキを食べたのは C ／ うそつきも C**
- **解説の核**: CとDが正反対のことを言っているため、この2人のどちらかが必ずうそつき。うそつきは1人だけなので、AとBは確実に本当のことを言っている。よってBの発言から犯人はC、そしてCがうそつきと決まる。

### ベンチマークC：2回だけの天秤（型4：情報の3分割）
- **問題**: 見た目が同じコインが9まいあり、1まいだけ少し軽いニセモノがまじっています。天秤を**2回だけ**つかってニセモノを見つけるにはどうすればよいでしょうか。
- **答え**: **9まいを「3まい・3まい・3まい」に分けてはかる**
- **解説の核**: 「天秤にのせない3まい」も手がかりになる。1回目に3まい vs 3まいをはかれば、軽い方（つり合えば残りの3まい）に候補を3まいまで絞れる。2回目にその3まいから1まい vs 1まいをはかれば確実に特定できる。

## 5. 作問・検証プロトコル（エージェント実行手順）

論理パズルは、たった1つの条件ミスで「答えが2つできてしまう」「どのケースも矛盾して答えがない」といった破綻が起きます。エージェントは出力前に必ず次の3ステップを実行してください。

### ステップ1：ゴールと「落とし穴」を先に設計する
1. どの型（型1〜型8）を使うか決める。
2. 先に**正解の状態**（例：犯人はC、橋の○×の配置など）を1つ確定させる。
3. 子どもが直感で引っかかりやすいポイント（例：4まい vs 4まいにしてしまう、端のカードをめくってしまう、など）を意識して条件を設計する。

### ステップ2：全ケース網羅による一意性の検証（必須）
問題文を書き終えたら、正解以外のすべてのパターンを頭の中（または内部検証）で試し、**「与えられた条件をすべて満たす答えが、本当に1通りしか存在しないか」**を確認すること。
- **チェック1（解の存在）**: 自分で設定した正解が、問題文のすべての条件を100%満たしているか。
- **チェック2（一意性）**: 他のパターンを当てはめたとき、必ずどこかの条件と矛盾して消えるか（別解がないか）。
- **チェック3（条件の過不足）**: なくても解けてしまう余計なヒントがないか、逆に情報が足りなくて勘に頼る箇所がないか。

### ステップ3：解説の品質チェック
解答・解説パートには、答えだけでなく必ず以下の2点を含めること。
1. **最初の一歩（着眼点）**: 「どこから考え始めればよいか」（例：「まず正反対のことを言っている2人に注目します」「まず道が2本しかない角から決めます」）。
2. **ひっかけの解消**: なぜ一見正しそうな別のやり方（例：4まいずつ分ける、「赤」のカードをめくる）ではダメなのかを簡潔に説明する。
