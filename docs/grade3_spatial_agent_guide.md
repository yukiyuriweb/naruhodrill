# 小学3年生向け・空間把握力問題作成 エージェント運用仕様書

本資料は、計算公式の暗記ではなく、**「頭の中で立体・視点・対称性・回転を操作して答えを導く力（空間把握力）」**を養う問題を生成するエージェントのための設計ガイドラインです。

---

## 1. 設計思想と「良い空間把握問題」の4原則

エージェントが作成する問題は、すべて以下の4つの原則を満たさなければなりません。

1. **先取り公式に頼らない**: 体積・表面積・角度の数値計算（4〜6年範囲）は使わず、視覚的な操作と論理だけで解けること。
2. **日常体験や具体物に根ざしたイメージができる**: 積み木、折り紙、鏡、窓からの景色、乗り物など、子どもが「自分の頭や手で試したくなる」題材を選ぶこと。
3. **同型問題の量産を避ける**: 同じ仕掛けを題材だけ変えたコピー（例：ガソリンスタンド→駐車場、きゅうり→にんじん）を作らず、第2章の8つのメカニズムから毎回異なる切り口を選ぶこと。
4. **図版の視覚的正確性を担保する**: 空間把握問題は図のわずかなズレが誤答や別解につながるため、座標・比率・左右反転・遠近関係を厳密に計算して図を描くこと。

---

## 2. 空間把握「8つの思考メカニズム」カタログ

エージェントは、以下の8つのメカニズムを組み合わせて多様な問題を作成します。

| 型 | メカニズム名 | 使う空間把握力・コアの仕掛け | 題材例 |
| :--- | :--- | :--- | :--- |
| **型1** | **視点の転換（一人称回転）** | 自分の体を進行方向や相手の向きに合わせて回転させ、左右・前後を判断する | 車の給油口、右左折後の建物の見え方、向かい合った人の左右 |
| **型2** | **複数視点と平面図の統合** | 2方向以上から見た3Dの風景を手がかりに、上空から見た地図（2D）上の位置を特定する | ホテルと新幹線の窓、公園のベンチと遊具の位置 |
| **型3** | **立体の切断と断面図** | 円柱・立方体・三角柱などを切ったときの「切り口の形」を想像する | 野菜の切り口、ブロックの切断、あり得ない断面探し |
| **型4** | **投影図からの立体復元** | 正面・横・真上から見た図を統合し、見えない部分を含む積み木の最小・最大個数を求める | 積み木の最大・最小個数、反対側から見たシルエット |
| **型5** | **対称性・折り紙の展開** | 複数回折って切った紙を広げたとき、折り目・中心・外周がどう開くかを想像する | 折り紙の穴あけ・切り落とし、切り絵の完成図 |
| **型6** | **鏡像反転・回転移動** | 鏡に映った文字や時刻の「全体の並び順」と「各パーツの向き」の両方を反転させる | 鏡の中のデジタル時計、鏡文字の読み取り、図形の90度・180度回転 |
| **型7** | **展開図の組み立て** | 展開図を組み立てたとき、どの辺とどの辺がくっつき、模様がどちらを向くかを見抜く | サイコロの目の向き、模様入り立方体の展開図 |
| **型8** | **影の形と重なり（遮蔽）** | 光の向きによる影の形や、手前の立体に隠れて「見える／見えない」部分を推理する | 懐中電灯の影、重なった図形の見える順番 |

## 3. 図版・選択肢・表記の厳格ルール

### 3.1 図版（SVG等）作成時の幾何学的チェック
空間把握問題は「図が命」です。以下の不整合が起きないよう、数値や座標で検証してから描画してください。
- **折り紙（型5）**: 折る方向（下→上、右→左）によって「折り目の辺」と「開いている辺」がどこになるかを座標で追跡し、中心（4枚重なる角）と外周を間違えないこと。
- **鏡像（型6）**: デジタル数字を使う場合は、`2 ↔ 5`、`0 ↔ 0`、`1 ↔ 1`、`8 ↔ 8` のように反転しても別の数字に見える組み合わせを活用し、7セグメントの向きを正確に描画すること。
- **リアルな情景問題（型1・型2等）**: 3Dの風景や乗り物の向きが重要な問題で、単純なSVG図形だけでは位置関係が伝わりにくい場合は、見取り図と平面図を併用するか、画像生成ツール等を活用して視覚的な誤解がないようにすること。

### 3.2 選択肢（ダミー）の作り方
選択問題にする場合は、子どもが陥りやすい**典型的な空間認識ミス**をダミー選択肢に混ぜます。
- **鏡像のミス**: 「並び順だけ逆にして、数字の向きを反転し忘れる」「数字だけ反転して、並び順を逆にし忘れる」
- **折り紙のミス**: 「折り目（中心）と外側の角を逆にしてしまう」「ひし形の穴を正方形の穴にしてしまう」
- **投影図のミス**: 「見えているブロックの数だけ足してしまう（見えない奥の支えを忘れる）」

### 3.3 小学3年生向けの表記ルール
- **漢字の配慮**: 小4以降の漢字には初出時にふりがなを付ける（例：`断（だん）面`、`鏡（かがみ）`、`折（お）り目`）。
- **専門用語の言い換え**: 「投影図」「鏡映反転」「対称軸」「回転対称」などの用語は使わず、「正面から見た形」「鏡に映った形」「折り目」「回した形」と表現する。

## 4. ベンチマーク問題集（目標水準の実例）

難易度の目線合わせとして、以下の3問（それぞれ異なるメカニズム）を基準にしてください。

### ベンチマークA：積み木のいちばん少ない数と多い数（型4：投影図からの立体復元）
- **問題**: 同じ大きさの立方体の積み木を、$3 \times 3$ の土台の上につみ上げました。正面から見た形が「左から3段・2段・1段」、右横から見た形も「手前から3段・2段・1段」のとき、つみ上げた積み木は**いちばん少ないときで何個**、**いちばん多いときで何個**ですか。
- **答え**: **いちばん少ないとき 6個 ／ いちばん多いとき 14個**
- **解説の核**: 最小はななめに「3・2・1」と置いた `3＋2＋1 ＝ 6個`。最大は各マスに正面・横どちらからもはみ出さない限界まで積んだ `6＋5＋3 ＝ 14個`。

### ベンチマークB：折り紙を切って広げた形（型5：対称性・折り紙の展開）
- **問題**: 正方形の折り紙を「下→上」に半分に折り、つぎに「右→左」に半分に折りました。そのあと、左上の角（外側の4つの角）と右下の角（折り目が重なる中心の角）をまっすぐ切り落として広げると、どんな形になりますか。
- **答え**: **外側の4つの角が切り落とされ、ど真ん中にひし形の穴が開いた形**
- **解説の核**: 折り目が重なる右下の角は広げると「紙の中心」になり、斜めに切ると正方形が45度傾いた「ひし形の穴」になる。左上の角は「外の4すみ」になる。

### ベンチマークC：鏡に映ったデジタル時計（型6：鏡像反転）
- **問題**: デジタル時計を鏡の前に置いたところ、鏡の中に「**15:20**」と映っていました。本当の時計が表している時刻は何時何分ですか。
- **答え**: **05:21（5時21分）**
- **解説の核**: 鏡に映すと「全体の並び順（左右）」と「数字1つ1つの向き（左右）」がどちらも反対になる。右から左へ読み直しながら「2↔5」を裏返すと `05:21` になる。

## 5. 作問・検証プロトコル（エージェント実行手順）

空間把握問題は「頭の中だけのイメージ」で作ると破綻しやすいため、出力前に必ず以下の3ステップで検証してください。

1. **ステップ1：実空間・数値モデルでの検算**:
   - 積み木なら $3 \times 3$ の数値表（高さ行列）を実際に書き出し、正面（列の最大値）と横（行の最大値）が一致するか確認する。
   - 折り紙なら4象限の座標で切り口を折り返し、穴の形と外周が正確に閉じるか確認する。
   - 視点・鏡像なら、実際に左→右・手前→奥の向きを1つずつ変換して逆算チェックする。
2. **ステップ2：一意性の確認**:
   - 別の解釈や、問題文に書いていない勝手な仮定（例：「土台の広さ」「積み木が浮いていないこと」など）が抜けていないか確認する。
3. **ステップ3：解説の具体化**:
   - 解説では「なぜその答えになるのか」だけでなく、「よくある間違い（例：数字の反転し忘れ、奥の見えない段の数え落とし）」に触れて、頭の中でイメージを修正できるように書く。
