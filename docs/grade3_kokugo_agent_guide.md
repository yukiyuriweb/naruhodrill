# 小学3年生向け・ハイレベル国語問題作成 エージェント運用仕様書

本資料は、小学3年生向けの国語教材（応用〜思考力レベル）を自動生成・編集するエージェントのための設計ガイドラインです。学習範囲・漢字配当の制約、読解・文法・語彙問題の設計パターン、および検算・品質チェックのルールを定義します。

---

## 1. プロジェクトの目的と目標難易度

### 1.1 ターゲット難易度
エージェントが作成する問題の標準難易度は、以下のレンジに設定します。

- **目標レンジ**: **市販のハイレベル問題集（『Z会グレードアップ問題集』など）の応用問題 〜 中学受験塾の小3クラスレベル**
- **学習体験のゴール**: 漢字の単純な書き取りや「文にそのまま書いてあることを探すだけ」の問題にとどまらず、**文と文のつながり（論理）や、登場人物の行動の裏にある気持ち、文の構造を自分で読み解く力**を養うことを目的とします。

### 1.2 難易度4段階ルーブリック（目線合わせ用）

| レベル | 位置づけ | 設問の特徴 | エージェントへの指示 |
| :--- | :--- | :--- | :--- |
| **Lv.1 基礎・標準** | 学校の教科書・カラーテスト | 直前の文をそのまま探せば答えが見つかる | 本仕様書では原則扱わない（導入用の小問1のみ可） |
| **Lv.2 応用（目標下限）** | 教科書の「確かめ」・市販応用ドリル | 段落をまたぐ整理、言い換え、接続語・指示語の判断 | **主力ターゲット**。根拠を自分の頭でつなぐ設問にする |
| **Lv.3 発展・思考力（目標上限）** | Z会グレードアップ・中学受験塾の小3クラス | 字数指定の抜き出し、文脈からの心情推測、複雑な主語・述語 | **主力ターゲット**。ひっかけ選択肢や条件付き記述を組み込む |
| **Lv.4 超難問（対象外）** | 高学年向け中学受験模試（抽象的評論文・長文記述） | 抽象語彙の多用、100字以上の自由記述 | 原則作成しない |

## 2. 小学3年生の学習範囲と厳守すべき制約

[文部科学省「小学校学習指導要領（国語 第3学年及び第4学年）」](https://www.mext.go.jp/a_menu/shotou/new-cs/youryou/syo/koku.htm)および[小3の漢字200字の学習内容](https://surala.jp/smart-print/kanji/article/learning/17460/)に基づき、出題範囲と表記ルールを厳守してください。

### 2.1 単元別・出題可能範囲一覧

| 領域 | 学習内容 | 小3で扱う具体的なポイント |
| :--- | :--- | :--- |
| **読むこと（説明文）** | 段落のまとまり・要点 | 段落どうしの関係（問いと答え、例とまとめ）、大事な言葉や文の抜き出し |
| **読むこと（物語文）** | 場面の様子・登場人物 | 登場人物の行動や会話からの気持ちの想像、場面の移り変わり |
| **言葉のきまり** | 文の組み立て・表記 | 主語と述語、修飾語、送り仮名、句読点・かぎ（「 」）の使い方、段落・行かえ |
| **語彙・辞書** | 言葉の増やし方 | 反対の意味・似た意味の言葉、国語辞典の使い方、ことわざ・慣用句・故事成語 |
| **伝統的な言語文化** | 短歌・俳句など | 易しい文語調の短歌・俳句のリズムや情景の読み取り |
| **文字・漢字** | 漢字200字・ローマ字 | 小3配当漢字200字（累計440字）、部首（へん・つくり）、訓令式を中心としたローマ字の読み書き |

### 2.2 漢字と表記の厳格ルール（重要）
小学3年生は1年間に**200字**（1〜3年生累計で**440字**）の漢字を学びます。エージェントは以下のルールを必ず守ってください。

1. **書き取り問題・漢字パズルの対象範囲**:
   - 子どもに「漢字を書かせる」設問は、**小1〜小3の配当漢字（440字）以内**に厳しく限定すること（小4以降の漢字を答えにしない）。
2. **本文・設問文中のふりがな（ルビ）ルール**:
   - 小4以降の配当漢字や難読語を本文・設問文・選択肢に使う場合は、初出時に必ず `飛（と）ぶ`、`特（とく）ちょう`、`関（かん）係` のように**ふりがなを付ける**こと。
   - 抜き出し問題で「そのまま書き抜きなさい」とする箇所に小4以上の漢字を含めると採点がぶれるため、**抜き出しの正解箇所には小3までの漢字またはひらがなのみを使う**こと。
3. **専門用語の先取り禁止**:
   - 「連体修飾語」「接続詞」「逆説」「換喩」「比喩（小5〜6）」などの文法用語はそのまま使わず、「くわしく説明する言葉」「つなぐ言葉」「反対のことを言うとき」など、小3が理解できる言葉に言い換えること。

## 3. 分野別の問題設計パターン（ハイレベル化の切り口）

### 3.1 読解問題（説明文・物語文）の作り方
国語は算数と異なり、**「本文の面白さ・論理の明確さ」**が問題の質を決めます。

- **本文の調達ルール（2パターン）**:
  - **パターンA（推奨・外部文章の活用）**: ユーザーから提供された文章や、著作権の切れた名作（青空文庫など）を本文として使い、エージェントがハイレベルな設問を作成する。
  - **パターンB（エージェントが短い文章を自作する場合）**: 長編の創作は避け、**250〜400字程度の短い説明文（動物・植物・身の回りの科学）**または**場面を1つに絞った物語文**にする。必ず「段落ごとの役割」や「対比（AとBのちがい）」が明確になる構成を書くこと。
- **ハイレベル設問の4つの型**:
  1. **接続語の穴埋め**: 「しかし（逆接）」「つまり（まとめ）」「たとえば（具体例）」「だから（理由→結果）」など、前後の論理関係を見抜かせる。
  2. **字数指定の抜き出し**: 「〜ため」「〜こと」など文末の形と正確な文字数を指定し、思い込みではなく本文から正確に探させる。
  3. **心情・理由の選択問題（紛らわしい4択）**: 4択のうち、1つは「本文と逆」、1つは「本文に書いていない勝手な想像」、1つは「一部だけ合っているがズレている」という**ひっかけの型**を意識して作る。
  4. **条件付き短文記述（20〜35字）**: 「『〜ので』という言葉を使って」「『〜』と『〜』の2つを入れて」など、書くべき要素を絞って採点しやすくする。

### 3.2 言葉のきまり・語彙の作り方
1. **主語・述語のひっかけ**: 「きのうの夕方、妹がひろってきた小さな子いぬは〜」のように、文の途中に別の「〜が」を含めて、文全体の主語を見抜かせる。
2. **修飾語（くわしくする言葉）の矢印整理**: 修飾語がどの言葉にかかっているかを問う。
3. **ことわざ・慣用句の文脈適用**: 意味を聞くだけでなく、短い会話文の空欄にぴったり合うことわざを選ばせる。

### 3.3 漢字・文字パズルの作り方
1. **共通の部品（部首）探し**: 「晴・暗・時・明（日）」「近・遠・通・道（⻌）」「思・息・感・悪（心）」のように、4つの漢字に共通する部品を見つけ、同じ部品を持つ別の漢字（小3まで）を答えさせる。
2. **同音異義語・反対の意味の熟語**: 「同じ音だが意味がちがう漢字（例：『きしゃ』＝汽車・記者）」「反対の意味の漢字の組み合わせ（例：開閉、売買、明暗）」を文脈に合わせて選ばせる。

## 4. ベンチマーク問題集（目標難易度の実例3問）

作問時の難易度・文字数・ふりがな・解説トーンの基準として、以下の3問を参照してください。

### ベンチマーク1：短い説明文の読解（Lv.2〜3 応用・発展）
- **本文**:
  > バッタやコオロギなどの虫は、うしろ足がとても大きく、遠くまでとぶことができます。これは、てきからすぐにはねてにげるためです。
  > （　ア　）、同じようにうしろ足が大きくても、トノサマバッタとコオロギでは、羽のようすがちがいます。トノサマバッタには長い羽があり、空を長く飛（と）ぶことができますが、コオロギの多くは羽が短く、空を飛ぶことはできません。
  > （　イ　）、うしろ足だけでなく、羽のつくりのちがいも、虫のにげ方や生き方に大きく関（かん）係しているのです。
- **設問**:
  1. （　ア　）（　イ　）に入る言葉を `① つまり　② しかし　③ たとえば` から1つずつ選びなさい。
  2. バッタやコオロギのうしろ足が大きいのは何のためですか。文章の中から「〜ため」の形になるように、**15字**でそのまま書き抜きなさい。
- **解答・解説**:
  - 1. **ア：②（しかし）** ／ **イ：①（つまり）**（前文との対比と、全体のまとめを見抜く）
  - 2. **てきからすぐにはねてにげるため**（第1段落の2文目から正確に15字を抜き出す）

### ベンチマーク2：言葉のきまり（Lv.2〜3 応用）
- **問題**: 次の文を読んで答えなさい。「きのうの夕方、妹がひろってきた小さな子いぬは、わたしのくつしたをうれしそうに口にくわえて走っていきました。」
  1. この文全体で、「何が（だれが）」にあたるいちばん大事な言葉（主語）を、4字で書き抜きなさい。
  2. この文の「どうした」にあたる述語を、文の最後から書き抜きなさい。
  3. 「小さな」は、どの言葉をくわしく説明していますか。
- **解答・解説**:
  - 1. **子いぬは**（「妹が」につられず、「〜は走っていきました」のつながりを見る）
  - 2. **走っていきました**
  - 3. **子いぬ**（または **子いぬは**）

### ベンチマーク3：漢字パズル（Lv.2 応用）
- **問題**: 次の4つの漢字に共通して使われている部品を答え、同じ部品を使った別の漢字（小3まで）を1つ書きなさい。
  - ① **晴・暗・時・明** ／ ② **近・遠・通・道** ／ ③ **思・息・感・悪**
- **解答・解説**:
  - ① **日（ひ・ひへん）** ／ 例：暑・昔・春・早・星・昼・曜・昭
  - ② **⻌（しんにょう）** ／ 例：週・進・運・追・返・速・送・遊
  - ③ **心（こころ・したごころ）** ／ 例：意・想

## 5. 作問・検算・出力の実行ルール（チェックリスト）

エージェントは問題を出力する前に、必ず以下の項目を自己検証してください。

### 5.1 徹底検算（特に文字数と漢字配当）
- **抜き出し文字数の1文字カウント**: 「◯字で書き抜きなさい」「◯字以内で」とした場合、句読点やひらがな・漢字を一字ずつ数え直し、**1字の狂いもないこと**を確認する。
- **小3配当漢字チェック**: 書き取り・漢字パズルの解答例に、うっかり小4以上の漢字（例：「映」「特」「加」「清」など）が混ざっていないか確認する。
- **選択肢の唯一性**: 選択問題で「別の解釈をすれば2つ正解になり得る」あいまいな選択肢を作らない。

### 5.2 出力構成（プリント／セット作成時）
1. **問題パート**:
   - 大問番号・テーマ
   - 読解文（段落番号や空欄記号を明記、小4以上の漢字にはふりがな）
   - 設問と解答欄（字数制限や「記号で」などの回答形式を明記）
2. **解答・解説パート（問題とは分けて後半に記載）**:
   - 正答（抜き出しは一字一句正確に）
   - **考え方のヒント（着眼点）**: どの言葉・どの段落に注目すればよいか
   - **くわしい解説**: 選択肢問題では「なぜ他の選択肢が違うのか」も簡潔に触れる
